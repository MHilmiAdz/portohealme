# 🌿 PortoHealme — Professional Portfolio

Welcome to **PortoHealme**, a modern, high-performance personal portfolio showcasing my journey in software engineering, mobile development, and creative design.

🔗 **Live Experience**: [https://mhilmiadz.github.io/portohealme/](https://mhilmiadz.github.io/portohealme/)

---

## ✨ The "Jade-Emerald" Transformation
This portfolio has been completely modernized with a **Jade-Green aesthetic**, moving away from standard templates to a custom-tailored, premium identity.

### 🚀 Key Features (2026 Edition)
- **Modern Aesthetic**: A deep "Emerald Night" color palette with high-contrast typography.
- **Kinetic Motion**: Implemented using **Framer Motion** for scroll-reveal, staggered lists, and fluid transitions.
- **Data-Driven Architecture**: All projects, experiences, and certifications are centralized in `src/data/` for easy maintenance.
- **Bento-Grid Specialization**: A modern UI layout showcasing core expertise in Android, Game Dev, and Cloud.
- **Responsive & Accessible**: Optimized for all devices with a mobile-first, glassmorphism-inspired navigation.

## 🛠️ Tech Stack
- **Frontend**: [React.js](https://reactjs.org/) (v19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (v4)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Hosting**: GitHub Pages

## 📂 Project Structure
```text
src/
├── assets/      # Optimized WebP images & SVG assets
├── components/  # Atomic UI components (Navbar, Card, etc.)
├── data/        # Centralized JSON-style data sources
└── Portofolio.jsx # Main layout & entry point
```

## 🛠️ Development & Deployment

### 1. Installation
```bash
npm install
```

### 2. Local Development
```bash
npm start
```

### 3. Build & Deploy
```bash
npm run deploy
```
